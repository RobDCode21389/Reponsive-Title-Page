# Responsive Landing Page – Asian Temple Theme

## Overview
This project is a **responsive landing page** designed to create an immersive and visually engaging user experience. The page is inspired by modern landing designs that use animation and motion to capture user attention, featuring an Asian temple theme.

The project was built using a tutorial as a **learning foundation**, then expanded to strengthen my understanding of UI structure, JavaScript integrations, and animation libraries.

## Features
- GSAP animations for smooth image and element transitions.
- Sakura.js particle effects that animate falling cherry blossom petals.
- Mobile-friendly navigation with toggle and close functionality.
- Fully responsive layout for desktop and mobile devices.
- Blurred header effect on scroll using `scrollY`.

## What I Learned
- How to integrate and manage multiple JavaScript libraries within one project.
- Creating a cohesive visual aesthetic that supports a webpage theme.
- Implementing scroll-based effects to enhance user experience.
- Structuring responsive layouts while maintaining animation performance.

## Technologies Used
- HTML
- CSS
- JavaScript
- GSAP.js
- Sakura.js

## Why This Project Matters
This project demonstrates my ability to combine multiple external libraries to create an engaging and artistic landing page. It reflects my growing understanding of UI design, animation workflows, and how JavaScript extensions can work together to support a clear visual concept.
